## 😎 About Me

I’m a frontend-focused web developer who builds modern, production-ready web applications using React,HTML, JavaScript Next.js, TypeScript, and Tailwind CSS. I enjoy turning ideas into clean, responsive, and interactive user interfaces with a strong focus on performance and user experience.

I’ve worked on real-world projects like PixHive, where I implemented structured app routing, reusable UI components, authentication flows, and state-driven layouts. I’m comfortable working with modern frontend architectures, integrating APIs, and collaborating with backend tools like Prisma and NextAuth to deliver complete solutions.

I’m constantly learning, experimenting, and refining my skills—especially in Next.js App Router, UI systems, and scalable frontend patterns. I enjoy solving problems, shipping features, and improving products one commit at a time😎
