## About Me

I’m an aspiring Software Engineer and Full-Stack Developer passionate about building modern, scalable, and production-ready web applications that solve real-world problems. I work with JavaScript, TypeScript, Python, React, Next.js, Node.js, Express.js, and Tailwind CSS to transform ideas into intuitive, responsive, and reliable digital experiences.

My experience spans frontend engineering, backend development, database design, REST API integration, authentication, and machine learning. Through projects such as Kiawara OnionLink and other web-based systems, I enjoy building practical solutions that connect users, streamline business operations, and turn data into meaningful insights. I’m also familiar with PostgreSQL, Prisma ORM, Git, and modern development workflows.

Beyond writing code, I’m driven by curiosity, continuous improvement, and the challenge of understanding how technology works beneath the surface. I’m currently expanding my knowledge of software architecture, secure application development, and cybersecurity, with the long-term goal of becoming a Cybersecurity Analyst and contributing to the development and protection of secure digital systems.

I believe great software goes beyond functionality — it should be thoughtfully designed, maintainable, secure, and built with real users in mind. I’m always learning, building, experimenting, and pushing myself to become a better engineer, one project and one commit at a time. 😎
